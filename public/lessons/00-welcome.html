You already know how to open a Win32 window, create a WGL context and draw with fixed-function OpenGL. This course adds the missing piece for building tools: a fast, practical user interface, with Dear ImGui. By the end you will have built the main panels of a small game-engine editor.

What is Dear ImGui?

Dear ImGui is a free C++ library by Omar Cornut for building immediate-mode graphical user interfaces. It doesn't create native Win32 controls. It produces a list of textured triangles, and your OpenGL code draws them on top of your scene, in the same window and the same frame.

  • Small and self-contained. A handful of .cpp files you compile into your program. No DLLs, no build system, no dependencies.
  • Renderer-agnostic. The core never calls OpenGL. Small "backend" files connect it to Win32, OpenGL, DirectX, Vulkan, SDL, GLFW and others.
  • Very little code per feature. A slider that edits a float is one line: ImGui::SliderFloat("Speed", &speed, 0.0f, 10.0f);
  • Built for programmers. It's designed for tools, debuggers and editors rather than end-user apps with heavy theming.

Many shipped games and engines use Dear ImGui for internal tools. The reason is simple: the UI is just code that reads and writes your engine's variables. You don't need a UI designer, data binding, or extra classes that you have to keep in sync.

Game-engine angle

Your engine already has a main loop that renders a frame every 16 ms. ImGui fits into that loop. Each frame you describe the editor panels, and ImGui draws them after your 3D scene. Pausing, stepping, inspecting and editing entities all happen inside the running game, with no separate editor process.

How this platform works

Each lesson page has two halves:

  1. Left: the lesson text. Explanations, code excerpts, tips, challenges and a short quiz.
  2. Right: a live code editor. It contains the lesson's starter code, a file called Lesson.inl. Edit it freely. Your changes are saved in the browser.

When you press Build & Run (or Ctrl+Enter), the local server:

  1. writes your code to Lesson.inl,
  2. compiles the mini engine OGL.c, which does #include "Lesson.inl" at the very bottom, with the real MSVC compiler (cl.exe /TP),
  3. links it with the prebuilt Dear ImGui objects, and
  4. opens a real native Win32 + OpenGL window running your UI.

Compiler errors and warnings show up in the output panel and are highlighted in the editor. Click one to jump to the line.

The two functions you write 
void Lesson_Init(void)   // called once, right after ImGui is initialised
{
}

void Lesson_UI(void)     // called every frame, between ImGui::NewFrame() and ImGui::Render()
{
    ImGui::Begin("Hello");
    ImGui::Text("Entities: %d", gEntityCount);
    ImGui::End();
}

Your code can use everything in the engine's ENGINE API block: gEntities, gCamera, gLight, gClearColor, Engine_AddEntity(), Engine_Log() and more. See the Engine API page.

The mini engine

Every lesson runs inside the same small "engine". It's the same classic Win32 + fixed-function OpenGL skeleton you already know, extended with a few features:

  • A scene of entities: Ground, Crate, Planet, Pyramid, Pillar. Each has a name, mesh, position/rotation/scale, color, texture, visibility and spin.
  • An orbit camera (gCamera) with target, yaw, pitch, distance and FOV.
  • A directional light (gLight), clear color, grid, wireframe and pause.
  • Mouse picking: left-click an object and gSelectedEntity changes.
  • A log (Engine_Log), frame-time history and procedural textures.

Using ImGui in your own projects

When you want ImGui in your own OGL.c outside this website, use the starter template. It sits next to this platform:

setup\ImGui_OpenGL_Template.zip        (also unzipped in setup\ImGui_OpenGL_Template\)
    OGL.c              Win32 + OpenGL + ImGui, ImGui code marked with //=====IMGUI===== banners
    run.bat            cl.exe /TP ... + link.exe -> bin\OGL.exe
    external\imgui\    Dear ImGui core + Win32 and OpenGL2 backends

⬇ Download ImGui_OpenGL_Template.zip

Open the x64 Native Tools Command Prompt for VS 2022, cd into the folder and run run.bat. Lesson 02 walks through every ImGui section of that OGL.c, line by line. The Setup page has installation help if the build tools are missing.
