Making it look like YOUR editor

The default ImGui look is recognisable at a glance, and that's fine for debug tools. For an editor people spend hours in, a consistent theme, a readable font and sensible spacing make a big difference. All of it comes from two places: the ImGuiStyle struct and the font atlas.

Built-in themes

ImGui::StyleColorsDark();      // the default (OGL.c calls this at startup)
ImGui::StyleColorsLight();
ImGui::StyleColorsClassic();   // the original purple-ish look

These functions only set colours. Each takes an optional ImGuiStyle*, so you can fill a style you are building instead of the live one. ImGui::ShowStyleSelector("Theme") is a ready-made combo that calls them.

ImGuiStyle: sizes and colours

ImGui::GetStyle() returns a reference to the live style. Change a field and the very next widget uses it:

Finding the right ImGuiCol

Open ImGui::ShowStyleEditor() (tick the box in the lesson's Theme window), go to the Colors tab and hover an entry. Most names are obvious. Header* is used by Selectable, TreeNode, CollapsingHeader and MenuItem highlights, and FrameBg* is the background of sliders, inputs and checkboxes.

Writing a custom theme function

A theme is just a function that fills an ImGuiStyle. Start from a built-in palette so every colour has a sensible value, then override what matters. Usually that means a few greys plus one accent colour used for active, checked and selected states:

static void L17_StyleEngine(ImGuiStyle *s)
{
    ImGui::StyleColorsDark(s);                 // complete base palette
    s->WindowRounding = 6.0f;  s->FrameRounding = 4.0f;  s->GrabRounding = 4.0f;
    s->FramePadding   = ImVec2(8, 4);
    s->WindowTitleAlign = ImVec2(0.5f, 0.5f);  // centred titles

    ImVec4 *c = s->Colors;
    ImVec4 accent = ImVec4(0.95f, 0.55f, 0.20f, 1.0f);
    c[ImGuiCol_WindowBg]         = ImVec4(0.11f, 0.11f, 0.12f, 0.96f);
    c[ImGuiCol_FrameBg]          = ImVec4(0.17f, 0.17f, 0.18f, 1.00f);
    c[ImGuiCol_CheckMark]        = accent;
    c[ImGuiCol_SliderGrabActive] = accent;
    c[ImGuiCol_Header]           = ImVec4(accent.x, accent.y, accent.z, 0.25f);
    ...
}

The lesson then rebuilds the whole style whenever the theme or scale changes: ImGuiStyle s; (defaults), fill the colours, s.ScaleAllSizes(scale), then ImGui::GetStyle() = s;.

Temporary changes: Push and Pop

To change the look of one widget or section, push a value onto ImGui's style stack and pop it afterwards:

ImGui::PushStyleColor(ImGuiCol_Button,        ImVec4(0.70f, 0.18f, 0.18f, 1.0f));
ImGui::PushStyleColor(ImGuiCol_ButtonHovered, ImVec4(0.85f, 0.25f, 0.25f, 1.0f));
ImGui::PushStyleColor(ImGuiCol_ButtonActive,  ImVec4(0.95f, 0.30f, 0.30f, 1.0f));
if (ImGui::Button("Delete selected")) { ... }
ImGui::PopStyleColor(3);                          // pop as many as you pushed

ImGui::PushStyleVar(ImGuiStyleVar_FrameRounding, 12.0f);         // float vars
ImGui::PushStyleVar(ImGuiStyleVar_FramePadding, ImVec2(16, 8));  // ImVec2 vars
ImGui::Button("Pill button");
ImGui::PopStyleVar(2);
Always balance Push/Pop, even on early returns

An unbalanced push "leaks" into every widget after it, and ImGui asserts at the end of the frame ("Missing PopStyleColor()"). Watch out for code like Push...; if (!open) return; Pop...;. A small RAII helper struct, or keeping Push/Pop on adjacent lines around a single widget, prevents this.

Fonts

ImGui rasterises TrueType fonts into a single texture atlas. Add fonts before the first frame. In this engine that means Lesson_Init(), which runs before the backend builds the font texture in its first NewFrame().

static ImFont *L17_LoadFont(const char *path, float sizePixels)
{
    ImGuiIO &io = ImGui::GetIO();
    FILE *f = fopen(path, "rb");                       // AddFontFromFileTTF asserts on a missing file
    if (f) { fclose(f); return io.Fonts->AddFontFromFileTTF(path, sizePixels); }
    return io.Fonts->AddFontDefault();                 // fallback: built-in ProggyClean 13 px
}

void Lesson_Init(void)
{
    L17_fontBody    = L17_LoadFont("C:\\Windows\\Fonts\\segoeui.ttf",  18.0f);  // FIRST = default font
    L17_fontHeading = L17_LoadFont("C:\\Windows\\Fonts\\segoeuib.ttf", 26.0f);
    L17_fontMono    = L17_LoadFont("C:\\Windows\\Fonts\\consola.ttf",  16.0f);
}
  • The first font added is the default. You can also set io.FontDefault = font, which is what ShowFontSelector() does.
  • Each size is a separate font. A 26 px heading is a second AddFontFromFileTTF call, not a scaled 18 px font.
  • Switching fonts works like styles: ImGui::PushFont(L17_fontHeading); ImGui::Text("Inspector"); ImGui::PopFont();. PushFont(NULL) pushes the default font.
  • Don't add fonts mid-frame. The atlas is locked between NewFrame() and Render(). Load every size you need up front.
Backslashes in paths

In a C string, "C:\Windows" contains the escape \W. Write "C:\\Windows\\Fonts\\segoeui.ttf" or use forward slashes: "C:/Windows/Fonts/segoeui.ttf".

On Windows, ImGui_ImplWin32_GetDpiScaleForHwnd(hwnd) gives you the monitor's scale factor (1.0 at 96 DPI, 1.5 at 144 DPI) to feed into both.

Game-engine angle

Ship your editor with its own font files (in an editor/fonts folder) instead of relying on C:\Windows\Fonts, which won't exist on Linux or a build machine. Keep a body font, a bold heading font, a monospace font for consoles and numbers, and often an icon font such as Font Awesome merged into the body font (ImFontConfig::MergeMode) for toolbar icons. Store theme choice and UI scale in the editor's user preferences. Use colour semantically: one accent for "active/selected", red only for destructive actions and errors, yellow for warnings. Avoid tinting panels by type. Users learn what colours mean, so keep them consistent.

// 2) soft light theme
static void L17_StyleSoftLight(ImGuiStyle *s)
{
    ImGui::StyleColorsLight(s);
    s->WindowRounding = s->FrameRounding = s->GrabRounding = s->PopupRounding = 8.0f;
    ImVec4 blue = ImVec4(0.20f, 0.45f, 0.90f, 1.0f);
    s->Colors[ImGuiCol_CheckMark]        = blue;
    s->Colors[ImGuiCol_SliderGrabActive] = blue;
    s->Colors[ImGuiCol_ButtonActive]     = blue;
    s->Colors[ImGuiCol_HeaderActive]     = blue;
}
// add L17_THEME_SOFT to the enum + name array, and a case in L17_ApplyTheme

// 3) coloured heading
static void L17_HeadingColored(const char *text, ImVec4 col)
{
    ImGui::PushFont(L17_fontHeading);
    ImGui::PushStyleColor(ImGuiCol_Text, col);
    ImGui::TextUnformatted(text);
    ImGui::PopStyleColor();
    ImGui::PopFont();
}
