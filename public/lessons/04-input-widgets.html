An inspector is mostly numbers: position, rotation, scale, speed, FOV. ImGui has three families of numeric widgets. All of them edit your variable through a pointer and return true on the frame the value changed.

The ...3 variants take a float[3], so they fit the engine's Entity::position, rotation and scale exactly:

Entity *e = &gEntities[gSelectedEntity];
ImGui::DragFloat3("Position", e->position, 0.05f);   // 0.05 units per pixel dragged
Ctrl+Click to type

Any slider or drag turns into a text box when you Ctrl+click it (or double-click a drag). Type 2.5 and press Enter. While dragging, hold Shift to go faster or Alt to go slower.

Format strings: units and precision

The format string controls what is displayed. The value is also rounded to that precision, unless you pass ImGuiSliderFlags_NoRoundToFormat.

ImGui::SliderFloat("FOV",      &gCamera.fov, 20.0f, 110.0f, "%.0f deg");   // 45 deg
ImGui::DragFloat  ("Time",     &gTimeScale,  0.01f, 0.0f, 5.0f, "%.2fx");   // 1.00x
ImGui::SliderInt  ("Lives",    &lives, 0, 9, "%d lives");
ImGui::DragFloat3 ("Rotation", e->rotation, 0.5f, -360.0f, 360.0f, "%.1f deg");

Slider flags

FlagEffect
ImGuiSliderFlags_AlwaysClampClamp to min/max even when Ctrl+Click typing. Without it, typed values can go out of range. Use it for scale (never 0) and pitch (+-89).
ImGuiSliderFlags_LogarithmicFine steps near the minimum, big steps near the max. Good for camera distance, light range, mass.
ImGuiSliderFlags_NoInputDisables Ctrl+Click typing.
ImGuiSliderFlags_WrapAroundDrag only: going past max wraps to min. Good for angles.
ImGuiSliderFlags_NoRoundToFormatKeep full precision even if the format shows fewer digits.
ImGui::DragFloat3("Scale", e->scale, 0.01f, 0.01f, 100.0f, "%.2f", ImGuiSliderFlags_AlwaysClamp);
ImGui::SliderFloat("Distance", &gCamera.distance, 1.0f, 200.0f, "%.1f m", ImGuiSliderFlags_Logarithmic);

InputText: editing a char buffer

ImGui edits text in place in a buffer you own. You must tell it the buffer size so that it never writes past the end:

// Entity::name is char[32]
ImGui::InputText("Name", e->name, sizeof(e->name));         // sizeof includes the terminating 0

static char search[64] = "";
ImGui::InputTextWithHint("##search", "Filter entities...", search, sizeof(search));

if (ImGui::InputText("Command", cmd, sizeof(cmd), ImGuiInputTextFlags_EnterReturnsTrue))
    RunCommand(cmd);                                          // only when Enter is pressed
Use sizeof on arrays, not pointers

sizeof(e->name) is 32 because name is an array. If you pass a char* pointer, sizeof gives 8 (the pointer size) and you can only type 7 characters. For std::string use misc/cpp/imgui_stdlib.h.

Return values and item queries

Every widget returns true on each frame its value changes. While dragging a slider, that is every frame. That's fine for live preview, but wrong for an undo system: one drag would create 60 undo entries per second. ImGui has item queries that refer to the last widget you submitted:

QueryTrue when
IsItemActivated()The user just started interacting (mouse down / focus). Snapshot the old value here.
IsItemActive()Every frame while held or being typed into
IsItemEdited()The value changed this frame (same as the return value)
IsItemDeactivated()The user just released / unfocused
IsItemDeactivatedAfterEdit()Released and the value changed. Push one undo command here.
static Entity before;
ImGui::DragFloat3("Position", e->position, 0.05f);
if (ImGui::IsItemActivated())            before = *e;                  // drag started
if (ImGui::IsItemDeactivatedAfterEdit()) UndoPush(index, before, *e);  // one entry per drag
Game-engine angle

This pattern of a snapshot on activate and a commit on deactivate-after-edit is how real editors get one undo step per gesture. It's also the right moment to mark the scene "dirty" (unsaved changes), send a network sync, or rebuild an expensive resource such as a physics shape. Do it when the user lets go of the slider, not while they drag it.

The example code

The Inspector window edits the selected entity: name (InputText), position, rotation and scale (DragFloat3), a logarithmic uniform-scale slider, spin settings, and a texture index (InputInt). Each edit goes through a small helper that uses IsItemActivated / IsItemDeactivatedAfterEdit to give you a working one-step Undo last edit button. Watch the edits so far counter: a long drag counts as one edit, not one per frame. Each edit also writes an Engine_Log line, which you'll display in the console lesson. The Camera window edits gCamera directly.
