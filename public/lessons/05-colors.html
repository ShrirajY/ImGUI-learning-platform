Colors are everywhere in an engine: sky, lights, materials, gizmos, debug lines. ImGui's color widgets edit plain float arrays in the 0..1 range, which is exactly what glColor4fv and glLightfv expect.

ColorEdit3 and ColorEdit4

bool ColorEdit3(const char* label, float col[3], ImGuiColorEditFlags flags = 0);
bool ColorEdit4(const char* label, float col[4], ImGuiColorEditFlags flags = 0);

A ColorEdit is a compact row: R, G and B (and A) drag boxes, a color square, and the label. Click the square to open a full picker popup. Right-click it for an options menu (RGB/HSV/Hex, 0..255 or 0..1). Like every widget it returns true when the color changed.

ImGui::ColorEdit3("Clear color", gClearColor);      // float[4] array, edits only the first 3
ImGui::ColorEdit3("Light color", gLight.color);     // float[3]
ImGui::ColorEdit4("Albedo",      e->color);         // float[4] RGBA, alpha used for blending
Environment
R:23G:26B:31 Clear color
R:255G:247B:230 Light color

ColorPicker3 / ColorPicker4

A picker is the big square or wheel, embedded directly in the window instead of in a popup. Use it when color editing is the main task of a panel:

ImGui::ColorPicker3("##wheel", gLight.color, ImGuiColorEditFlags_PickerHueWheel);
ImGui::ColorPicker4("Tint", tint, ImGuiColorEditFlags_AlphaBar, originalTint);  // last arg: "before" swatch

ColorButton: a clickable swatch

bool ColorButton(const char* desc_id, const ImVec4& col, ImGuiColorEditFlags flags = 0,
                 const ImVec2& size = ImVec2(0, 0));

ColorButton only shows a color and returns true when clicked. It takes an ImVec4 by value, so it never edits anything itself. That makes it the building block for palettes, recent-color lists and material thumbnails:

if (ImGui::ColorButton("Red", ImVec4(0.9f, 0.2f, 0.2f, 1.0f), 0, ImVec2(24, 24)))
{
    e->color[0] = 0.9f; e->color[1] = 0.2f; e->color[2] = 0.2f;
}
Palettes need unique IDs

In a loop, don't give every swatch the same desc_id. Format a unique one ("Swatch 3") or wrap each one in PushID(i)/PopID(). Lesson 06 explains why.

Useful flags

FlagEffect
ImGuiColorEditFlags_NoInputsOnly the color square, no R/G/B boxes. Compact for tables and inspectors.
ImGuiColorEditFlags_NoLabelHide the text label (it still appears in the tooltip and picker).
ImGuiColorEditFlags_NoAlphaIgnore alpha (ColorEdit4/ColorButton show RGB only).

ImGui::ColorEdit4("##c", e->color, ImGuiColorEditFlags_NoInputs | ImGuiColorEditFlags_NoLabel);

Three ways to store a color

TypeLooks likeUsed by
float[3] / float[4]{ 0.9f, 0.2f, 0.2f, 1.0f }Your engine data, ColorEdit, ColorPicker, glColor4fv
ImVec4ImVec4(0.9f, 0.2f, 0.2f, 1.0f)TextColored, ColorButton, style colors (.x .y .z .w = r g b a)
ImU32IM_COL32(230, 51, 51, 255)Draw lists (AddLine, AddRectFilled). Packed 8 bits per channel, 0..255.

Conversions:

ImVec4 v   = ImVec4(e->color[0], e->color[1], e->color[2], e->color[3]);   // float[4] -> ImVec4
ImU32  u   = ImGui::ColorConvertFloat4ToU32(v);                             // ImVec4 -> ImU32
ImVec4 back = ImGui::ColorConvertU32ToFloat4(u);                            // ImU32 -> ImVec4

float h, s, val;
ImGui::ColorConvertRGBtoHSV(e->color[0], e->color[1], e->color[2], h, s, val);  // h,s,v in 0..1
ImGui::ColorConvertHSVtoRGB(h, s, val, e->color[0], e->color[1], e->color[2]);
Pointer tricks

Because ColorEdit4 takes a float*, you can pass &myImVec4.x to edit an ImVec4 directly. The four floats are contiguous.

Game-engine angle

An environment or lighting panel is often the first thing artists ask for. Sky color, sun color, ambient and fog, with presets like "Day / Sunset / Night", are just ColorEdits pointing at engine globals. Material palettes built from ColorButton become your first "asset" UI. Later, you can drag a swatch onto an entity with drag and drop (lesson 13). ColorButtons are already drag sources by default.

The example code

  • Environment: gClearColor, the light color as an HDR float editor, the ambient color in HSV, an optional embedded hue wheel, and Day/Sunset/Night presets.
  • Material: the selected entity's RGBA color with an alpha bar (try alpha 0.4), a 12-swatch ColorButton palette, a compact square-only editor, and live conversions to ImU32, HSV and hex, including "shift hue" and "random color" buttons that use the HSV helpers.

Challenges

  1. Add a "Recent" row: every time a palette swatch is applied, remember the color in a static ImVec4 recent[6] ring buffer and show those swatches too.
  2. Add a "Tint all" button that multiplies every entity's RGB by the light color.
  3. Show a ColorPicker4 for the selected entity that also displays the color it had when it was selected, as the reference ("before") color.
Show solution 
// 1 - recent colors
static ImVec4 recent[6];
static int    recentCount = 0, recentNext = 0;
// ...inside the palette click:  recent[recentNext] = L5_palette[i];
//                               recentNext = (recentNext + 1) % 6;
//                               if (recentCount < 6) recentCount++;
ImGui::SeparatorText("Recent");
for (int i = 0; i < recentCount; i++)
{
    ImGui::PushID(i);
    if (ImGui::ColorButton("recent", recent[i], ImGuiColorEditFlags_NoAlpha, ImVec2(22, 22)))
    { e->color[0] = recent[i].x; e->color[1] = recent[i].y; e->color[2] = recent[i].z; }
    ImGui::PopID();
    ImGui::SameLine();
}
ImGui::NewLine();

// 2 - tint all
if (ImGui::Button("Tint all"))
    for (int i = 0; i < gEntityCount; i++)
        for (int k = 0; k < 3; k++)
            gEntities[i].color[k] *= gLight.color[k];

// 3 - picker with reference color
static float refColor[4];
static int   refFor = -1;
if (refFor != gSelectedEntity)       // selection changed: remember the starting color
{
    for (int k = 0; k < 4; k++) refColor[k] = e->color[k];
    refFor = gSelectedEntity;
}
ImGui::ColorPicker4("##picker", e->color, ImGuiColorEditFlags_AlphaBar, refColor);
