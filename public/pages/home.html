What you will build

Core widgets

Windows, text, buttons, sliders, drags, colour pickers and the ID stack.

Editor panels

Scene hierarchy with context menus, an inspector, combos, and sortable tables.

Engine tools

Menu bar with shortcuts, a console with commands, drag & drop, and input capture.

Visual tools

Frame-time profiler, HUD overlays, draw-list gizmos, world-space labels, and an asset browser.

Look & feel

Custom engine themes, fonts and style variables.

Capstone

Everything combined into one mini engine editor around the 3D viewport.

The sandbox engine

Every lesson runs inside a small engine host (sandbox/engine/OGL.c). It has a scene of entities (cubes, spheres, a pyramid...), an orbit camera, a directional light, mouse picking, a log and procedural textures. Your ImGui code reads and edits that engine state, exactly as an editor does in a real engine. See Engine API.
