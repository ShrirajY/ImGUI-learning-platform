Engine API

Everything your lesson code can use besides ImGui itself. It is all defined in sandbox/engine/OGL.c, and your Lesson.inl is included at the bottom of that file.

Lesson hooks (you write these)

void Lesson_Init(void);   // once, after ImGui is initialised and before the first frame (load fonts, set style, log)
void Lesson_UI(void);     // every frame, between ImGui::NewFrame() and ImGui::Render()

Frame order: RenderScene() → NewFrame() → Lesson_UI() → camera input (checks io.WantCaptureMouse/Keyboard) → Render() → SwapBuffers().

Scene / entities

enum MeshType { MESH_CUBE, MESH_SPHERE, MESH_PYRAMID, MESH_CYLINDER, MESH_PLANE, MESH_COUNT };
const char *gMeshNames[MESH_COUNT];      // "Cube", "Sphere", ...  (ready for ImGui::Combo)

struct Entity {
    char  name[32];
    int   mesh;            // MeshType
    float position[3];
    float rotation[3];     // Euler degrees X, Y, Z
    float scale[3];
    float color[4];        // RGBA 0..1  (alpha < 1 = transparent)
    int   texture;         // index into gTextures, -1 = none
    bool  visible;
    bool  spin;            // auto-rotate around Y
    float spinSpeed;       // deg/s
};
Entity gEntities[MAX_ENTITIES];          // MAX_ENTITIES = 128
int    gEntityCount;
int    gSelectedEntity;                  // -1 = none. Left-click in the 3D view changes it.
FunctionDescription
int Engine_AddEntity(const char *name, int mesh)Adds an entity and returns its index (-1 if the scene is full).
void Engine_RemoveEntity(int index)Removes it and shifts the later entities down. Fixes up gSelectedEntity.
int Engine_DuplicateEntity(int index)Copies an entity, offset by +1.5 on X.
void Engine_ResetScene() / Engine_ClearScene()Restores the default 5-entity scene, or removes everything.
void Engine_FocusEntity(int index)Moves the camera target to the entity.
bool Engine_WorldToScreen(const float world[3], ImVec2 *out)Projects a 3D point to ImGui screen coordinates. Returns false if it is behind the camera.
void Engine_Quit()Closes the window.

Default controls

Right mouse dragOrbit camera
Middle mouse dragPan
Mouse wheelZoom
Left clickSelect entity (sets gSelectedEntity)
WASD / QEMove camera target
F11 / EscFullscreen / quit

All of these are ignored while ImGui wants the mouse or keyboard, for example while you hover a window or type into a text field.
