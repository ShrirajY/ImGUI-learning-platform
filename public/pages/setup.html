Setup

There are two parts: the starter template, which you can forward to anyone, and this learning platform.

1. Starter template (ImGui + OpenGL)

The minimal project: a Win32 window, an OpenGL triangle and one ImGui window. It is the same OGL.c structure used throughout the lessons.

⬇ Download ImGui_OpenGL_Template.zip Setup guide (.md) 

ImGui_OpenGL_Template/
  external/imgui/   Dear ImGui core + imgui_impl_win32 + imgui_impl_opengl2
  OGL.c             window + OpenGL rendering + ImGui (compiled as C++ with /TP)
  run.bat           compile -> link -> run
  README.txt

Build it

  1. Install Visual Studio 2022 (Community is free) with Desktop development with C++.
  2. Open x64 Native Tools Command Prompt for VS 2022 from the Start menu.
  3. cd into the unzipped folder and type run.bat.
cl.exe /c /EHsc /std:c++17 /TP /I external/imgui OGL.c external/imgui/imgui*.cpp ... /Fo"intermediate\\"
link.exe intermediate\*.obj User32.lib GDI32.lib OpenGL32.lib /SUBSYSTEM:WINDOWS /OUT:bin\OGL.exe
bin\OGL.exe
Why /TP?

Dear ImGui is C++ (namespaces like ImGui::Begin, default arguments). /TP tells MSVC to compile every file, including OGL.c, as C++.

2. This learning platform

FileWhat it does
setup.batRun once. Checks for and installs Node.js (winget), checks for and offers to install the Visual Studio C++ Build Tools, makes sure the Dear ImGui sources are in sandbox/external/imgui (copying them from ../setup or downloading them from GitHub), then does a test build.
run.batStarts the local server on http://localhost:5173 and opens your browser. Runs setup automatically the first time.

How Build & Run works

  1. The browser sends your editor code to the local Node server, which listens on 127.0.0.1 only.
  2. The server writes it to sandbox/work/Lesson.inl.
  3. It compiles sandbox/engine/OGL.c, which #includes Lesson.inl at the bottom, using cl.exe /TP. The ImGui library is compiled once and cached in sandbox/cache/obj.
  4. It links the exe, closes any previous lesson window, and launches the new one.
  5. Compiler errors are mapped back to lines in the editor. Click an error to jump to it.

Troubleshooting

ProblemFix
Status pill says offlineStart the site with run.bat. Opening index.html directly cannot compile anything.
Status pill says MSVC missingRun setup.bat again and accept the Build Tools install, or install VS 2022 with the C++ workload.
Port 5173 already in useThe site is probably already running. Otherwise run set PORT=5174 and then run.bat.
First build is slowThe first build compiles the ImGui library once (about 10-40 s). After that, builds take about 2-3 s.
Lesson window doesn't appearCheck the taskbar, since it may have opened behind the browser. Press Stop, then Build & Run again.
